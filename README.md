# -Password-Cracking-Hash-Extraction-Credential-Auditing
🔐 Week 3 Completed: Password Cracking, Hash Extraction &amp; Credential Auditing

This project taught me one thing: a weak password is not a password at all.

This was the project I was most excited about in Week 3 of my cybersecurity journey — and it did not disappoint! 🚀

I had the opportunity to get hands-on experience with password-recovery and auditing techniques through two practical labs:

🔹 W3-PM1: John the Ripper & Johnny GUI

* Extracted password hashes from password-protected PDF files.
* Used John the Ripper to perform offline dictionary attacks.
* Explored Johnny GUI to manage and monitor password-cracking sessions.
* Successfully recovered lab passwords and captured the lab flags.

🔹 W3-PM2: NetworkWalks Hash Calculator & Password Cracker

* Used browser-based hashing and password-auditing utilities.
* Extracted PDF hashes in the $pdf$ format.
* Conducted dictionary-based password testing.
* Evaluated password strength against common wordlists.

💡 Key Lessons Learned:

* How password hashes are extracted and analyzed.
* How offline dictionary attacks work.
* Why weak and predictable passwords are vulnerable.
* The importance of strong, unique passwords.
* How to document findings and recommend security improvements.

🛡️ Security Recommendations:

* Use long, unique passwords or passphrases.
* Use password managers.
* Apply strong encryption to sensitive files.
* Implement multi-factor authentication.
* Protect credentials and sensitive hash data.

This experience reminded me that cybersecurity is not just about running tools. It’s about understanding vulnerabilities, analyzing results, thinking critically, and knowing how to strengthen security.
